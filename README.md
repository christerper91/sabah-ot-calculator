# Sabah OT Calculator - Deploy Guide

## Files Included
- `index.html` — The calculator app (everything in one file)
- `manifest.json` — PWA config (makes it installable)
- `icon-192.png` — App icon (small)
- `icon-512.png` — App icon (large)

---

## 🚀 How to Deploy (Free) — Netlify Drop

**Time: ~2 minutes, no account needed**

1. Go to **https://app.netlify.com/drop**
2. Drag and drop ALL 4 files into the browser
3. Done! You'll get a live URL like `https://random-name.netlify.app`

### Add to your phone:
- **Android**: Open the URL in Chrome → tap ⋮ menu → **"Add to Home Screen"**
- **iPhone**: Open the URL in Safari → tap Share ↑ → **"Add to Home Screen"**

It will appear as a real app on your phone!

---

## Alternative: GitHub Pages (Free, permanent)

1. Create a GitHub account at github.com
2. Create a new repository (e.g. `sabah-ot-calc`)
3. Upload all 4 files
4. Go to Settings → Pages → Source: main branch
5. Your app is live at `https://yourusername.github.io/sabah-ot-calc/`
